A cross-encoder re-ranker is a small neural model that takes a (query, document) pair as input and outputs a single relevance score. Unlike the bi-encoder used for vector search, which encodes query and document independently, the cross-encoder lets the query and document attend to each other at every layer — so it captures fine-grained interactions that bi-encoders miss.

The catch is cost. A cross-encoder cannot pre-compute document embeddings, so you have to run the model on every (query, candidate) pair at query time. For a top-1000 candidate set, that is 1000 transformer forward passes per query — typically 100-1000ms of GPU time, an order of magnitude slower than vector search.

The standard pattern is two-stage retrieval. Stage 1: bi-encoder + HNSW returns the top-1000 candidates in a few milliseconds. Stage 2: cross-encoder re-ranks those 1000 candidates and returns the top-k (usually k=5-20) in a few hundred milliseconds. The two stages compose: the bi-encoder provides high recall cheaply, the cross-encoder provides high precision expensively, and the user only ever sees the final top-k.

The quality lift is large. On benchmarks like BEIR, adding a cross-encoder reranker on top of a strong bi-encoder typically gains 10-20 nDCG points — often more than the gap between the best and worst bi-encoders. The model is small (a BERT-base or RoBERTa-base fine-tuned on MS MARCO, only ~100M parameters) and the inference is trivially batchable, so the latency cost is manageable.

Common open-source rerankers include cross-encoder/ms-marco-MiniLM-L-12-v2 (a small, fast default), BGE-reranker (stronger on multilingual), and Jina-reranker. Cohere and Voyage also sell hosted rerankers that are competitive with the best open-source models for a few cents per thousand queries.

A common pitfall is feeding the reranker the top-20 from the bi-encoder. That is too small — the reranker cannot recover a relevant document that the bi-encoder missed. Always pass at least the top-100, and ideally the top-1000, to give the reranker room to work.
